# SoftproInnovation

A full-stack e-commerce web application for electronics and robotics
components, built with the MERN stack as part of my software engineering
internship at Softpro India Computer Technologies.

## Features
- Browse products in the catalogue
- Add and manage items in a shopping cart
- User registration and login (frontend + backend)
- React frontend connected to a Node.js/Express REST API via Axios

## Tech Stack
- **Frontend:** React, Bootstrap, Axios
- **Backend:** Node.js, Express
- **Database:** MongoDB
